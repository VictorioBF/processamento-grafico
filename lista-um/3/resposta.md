a) Para representar o triangulo com VBO e VAO, uma configuracao possivel usa um unico VAO para guardar o estado dos atributos. Sao criados dois VBOs: um armazena as posicoes dos tres vertices em coordenadas (x,y,z), outro armazena as tres cores (r,g,b) como floats. Cada VBO e preenchido com os dados e enviado para a GPU com glBufferData. No VAO, para cada VBO, usa-se glVertexAttribPointer para definir o layout (tamanho, tipo, stride, offset) e glEnableVertexAttribArray para ativar o atributo. O indice do atributo de posicao pode ser 0 e o das cores 1. Alternativamente, os dados podem ser intercalados em um unico VBO com stride calculado.

b) No vertex shader, esses atributos sao identificados por variaveis de entrada (in) declaradas no comeco do shader. Por exemplo, in vec3 position; e in vec3 color;. A correspondencia com os buffers e feita pelo indice de localizacao (location) definido via layout qualifier no shader (layout (location = 0) in vec3 position;) ou via glBindAttribLocation antes do link do programa. O shader recebe a posicao para calcular gl_Position e repassa a cor para o fragment shader como uma variavel out, permitindo a interpolacao entre os vertices.
